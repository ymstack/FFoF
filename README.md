# ym-launchpad

Single-page parody website: Founding Fathers of Feminism.

## Local preview (localhost)

From this project folder, run:

```bash
python3 -m http.server 8080
```

Then open:

http://localhost:8080

Stop the server with `Ctrl + C`.

## Deploy to your future domain

This project is static HTML/CSS, so you can host it on:

- GitHub Pages
- Netlify
- Vercel (static)
- Cloudflare Pages

Upload `index.html` (and any future assets), then connect your custom domain in your host dashboard.
